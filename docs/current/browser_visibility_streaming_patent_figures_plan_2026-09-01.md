# 浏览器三维实例流式调度专利附图规划

日期：2026-09-04
对应专利文件：`browser_instance_visibility_streaming_patent_application_2026-09-02.md`

## 制图目标

附图说明一条连续的数据流：浏览器在主体模型资源尚未全部下载时，先利用体量较小的实例运行数据计算区域可见性；工作线程首次查询返回压缩实例编号，区域复用时返回集合差量，同时给出资源调度信号；页面端将调度信号与首屏资源顺序合并到统一资源状态表；资源按照需求等级和当前状态依次完成下载、解析、挂载和驻留；驻留资源中的实例再按当前显示集合进入画面。

附图不出现工程类名、脚本名、着色器字段和实验版本。图中使用“实例运行数据”“区域可见性计算”“资源容器”“当前显示实例集合”等说明书已经定义的通用术语。图 1、图 4 至图 8 说明通用系统流程；图 2 和图 3 进一步展开一项可行的模型实施方式，并标出具体特征维度，使离线编码、视点区域查询和轻量神经网络之间的数据关系可以直接理解。

## 制图规范

- 使用白底、深色轮廓和低饱和语义色。离线处理使用浅蓝，固定数据使用浅绿，批量计算使用浅紫，资源调度使用浅橙，实例显示使用浅青。模块同时依靠标题、轮廓和空间分区区分，灰度打印时仍能辨认。
- 系统或阶段使用带标题的分区，数据流使用单向箭头。图内技术对象采用统一图形语义：立体块表示场景构件或渲染实例，视锥表示相机覆盖范围，节点网络表示关系聚合或神经计算，矩阵表示固定特征、系数表或实例位图，曲线表示方向和距离条件下的响应，芯片表示 GPU 批量计算，文档叠层表示 GLB 等主体模型资源，圆柱表示常驻数据或资源容器，菱形表示条件判断。
- 图中文字使用简短中文名词；较长解释放在说明书的附图说明和具体实施方式中。
- 统一使用阿拉伯数字作为参考标号，同一对象在不同附图中沿用同一标号。
- 系统总览图不把固定视场角、特征维数或网络层数写成必要条件；模型结构图可以标出本实施例的实际维度，但在说明书中明确其属于可调整参数。
- 每张图的 `.drawio` 文件是可编辑原稿；SVG 和 PNG 是从 draw.io 原稿导出的提交与预览版本。
- 常规附图画布为 `1800×1100`，时序图为 `1800×1300`。线宽和字号按缩小至三分之二后仍可辨认设置。
- `100`、`200`、`300` 等数字是说明书中的参考标号，用于跨附图指向同一技术对象，不表示执行顺序；执行顺序由箭头和“步骤一”等文字表示。

图形符号用于说明技术对象及数据形态，不限定三维资源的文件格式、特征矩阵的存储布局、神经网络的实际节点数量或图形处理器的硬件外形。网络图只展示计算层次，矩阵和位图中的着色单元只表示被选中特征或实例。

国家知识产权局关于说明书附图的公开答复指出，附图一般使用黑色墨水绘制，清楚描述技术内容确有需要时可以提交彩色附图；线条应当均匀清晰，附图缩小到三分之二后仍应能分辨细节。本套图使用颜色帮助阅读技术交底，但不以颜色作为唯一信息载体。正式提交前可由专利代理师按申报系统和案件需要决定保留颜色或作灰度输出。

## 文件组织

附图源文件和预览图统一保存于：

```text
docs/figures/patent_browser_streaming/
  figure_01_system_architecture.drawio / .svg / .png
  figure_02_offline_model_pipeline.drawio / .svg / .png
  figure_03_visibility_model_architecture.drawio / .svg / .png
  figure_04_browser_loading_sequence.drawio / .svg / .png
  figure_05_runtime_visibility_pipeline.drawio / .svg / .png
  figure_06_viewcell_frustum_reuse.drawio / .svg / .png
  figure_07_dual_granularity_streaming.drawio / .svg / .png
  figure_08_incremental_rendering.drawio / .svg / .png
```

`generate_figures.mjs` 生成原生 draw.io XML，`render_figures.mjs` 调用 draw.io 导出 SVG 和 PNG。附图内容调整后应重新生成，并逐图检查箭头绕行、文字裁切、参考标号、灰度打印和缩小显示可读性。

当前导出使用 draw.io `31.3.2`。Linux 无显示环境由用户级 Xvfb 提供虚拟显示；也可以通过 `DRAWIO_BIN` 和 `XVFB_BIN` 指定其他安装位置。完整重建命令为：

```bash
node docs/figures/patent_browser_streaming/generate_figures.mjs
node docs/figures/patent_browser_streaming/render_figures.mjs
```
