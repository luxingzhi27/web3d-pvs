# 方向条件化反事实遮挡表征快速评价

- 日期：2026-08-19
- 实验：`pvs_direction_conditioned_counterfactual_occlusion_v1`
- 场景：HKUST v3
- 训练：seed `20260801`，四组均从头训练 `8 epoch × 100 step`
- 阈值：每个 checkpoint 只用自身 calibration 冻结
- 评价：完整 `213` 个 validation view-cell，未读取 test
- 默认前端：未修改

## 评价目的

本轮分别验证两个因素：四维方向条件化门控关系特征，以及视觉加权的同实例反事实排序损失。四组保持同一数据、候选、GT、基础模型和前端预算。A/B 关闭反事实损失，C/D 开启；A/C 使用原始四维方向基，B/D 使用四维等量门控关系特征。

## 安全工作点结果

`不合格` 表示 calibration 选择的正式安全阈值没有通过 validation weighted recall `>0.99` 及其单侧 95% 下界 `>0.99`；表中 A/B 使用各自 checkpoint 的 calibration 诊断阈值回放，只用于观察分数分布，不能当作正式安全模型，也不能在 validation 上另选阈值补救。

| 变体 | 正式安全 | 阈值 | agg precision | agg recall | weighted recall / LCB | accuracy | balanced accuracy | useful cull | bad cull | 平均预测 | GLB 字节削减 |
|---|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| A 原始方向基 | 不合格 | 0.03 | 0.0443 | 1.0000 | 1.0000 / 1.0000 | 0.0443 | 0.5000 | 0.0000 | 0.0000 | 5174.39 | 0.00% |
| B 门控关系 | 不合格 | 0.02 | 0.0443 | 1.0000 | 1.0000 / 1.0000 | 0.0443 | 0.5000 | 0.0000 | 0.0000 | 5174.38 | 0.00% |
| C 原始方向基 + 反事实 | 合格 | 0.15 | 0.3440 | 0.5557 | 0.99347 / 0.99161 | 0.9334 | 0.7533 | 0.9088 | 0.0197 | 370.10 | 40.79% |
| D 门控关系 + 反事实 | 合格 | 0.10 | 0.1067 | 0.8354 | 0.99823 / 0.99734 | 0.6832 | 0.7558 | 0.6462 | 0.0073 | 1792.93 | 8.36% |

普通 recall 较低但 weighted recall 较高，表示漏掉的主要是低视觉权重实例；这仍需后续 Color-ID 图像评价确认，不能仅凭 weighted recall 宣称画面无损。C 在安全约束下比 D 少预测约 `1423` 个实例，precision 高 `0.2372`，GLB 字节削减高 `32.43` 个百分点。D 的 aggregate balanced accuracy 仅高 `0.0025`，不足以抵消其分类与资源退化。

反事实损失改善了同一实例在可见和不可见视点之间的顺序，静态实例偏置无法解释这一增益。当前门控公式在没有反事实损失时只有小幅 AUC 增益；与反事实损失组合后出现负交互，表明四维逐元素缩放破坏了原方向基中已经有用的信息。低维暴露头的 MAE 也由 A 的 `0.0758` 上升到 B 的 `0.5327`，说明当前四维瓶颈未形成可用的区域暴露表征。

## 前端预算

| 项目 | 实测或固定值 |
|---|---:|
| 固定实例表 | `124D FP16` |
| HKUST 固定表字节 | `4,670,088` |
| 查询输入 | `130D` |
| 查询权重 | `45,198 bytes` |
| 全部神经资产 | `4,748,630 bytes`，约 `4.53 MiB` |
| 完整运行包 | `5,480,464 bytes`，约 `5.23 MiB` |
| 上限 | `7 MiB` |
| 在线 view-cell 查询 | 每个候选批次一次 |

完整运行包还包含实例 AABB、实例到 GLB 映射和元数据，仍低于 `7 MiB`。C 使用原始方向基；反事实排序只改变训练目标，不增加任何导出权重、固定特征或在线算子，因此其浏览器查询路径与原方向基模型一致。CUDA 完整 validation 回放为每组约 `2.4-2.6 s`；该值包含 `213` 个 view-cell 的数据回放，不能替代浏览器 WebGPU 或真实移动设备延迟。由于门控关系特征未通过离线保留条件，本轮没有修改前端 shader，也没有开展移动端正式性能评价；三种子长训模型只有通过硬件 WebGPU parity 和移动端 `10k` 候选 p95 `<50 ms` 后才能接入默认前端。

## 结论

视觉加权同实例反事实排序是本轮唯一通过快速保留条件的因素。它在不增加前端资产和查询维度的情况下，把安全工作点从“预测几乎全部候选”推进到平均预测 `370.10` 个实例，并改善同实例跨视角分离。当前四维门控关系特征不保留；后续若继续关系表征研究，应保留原始方向基信息，并避免用单一逐元素缩放覆盖主干输入。

自动 runner 在通过 weighted recall 安全门的成员中，依次按 useful cull、GLB 字节削减、balanced accuracy、precision、accuracy 和更少预测数量排序，因此选择 C 作为下一轮快速改进起点。D 的 aggregate balanced accuracy 只高 `0.0025`，但 C 的 useful cull 高 `0.2626`、GLB 字节削减高 `0.3243`，且平均少预测约 `1423` 个实例；这更符合前端资源与运行成本约束。正式晋级仍需要三种子长训、图像指标和硬件 WebGPU/移动端评价。
