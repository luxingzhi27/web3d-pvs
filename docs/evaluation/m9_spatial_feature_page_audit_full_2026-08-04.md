# M9 全量空间特征页语义审计

日期：2026-08-04  
状态：空间页候选语义与资源目录子门通过；浏览器端到端延迟仍未完成

## 评价范围

本次使用 HKUST 模型查询视场角 `66°`、真实渲染视场角 `60°`、后退相机偏移 `3.464101552963257 m`、远裁剪面
`2,000 m` 和完整 `7,999` 个 pose。比较页查询与完整实例 AABB 扫描得到的后退视锥候选集合；两条路径使用相同的
实例 AABB、相同的模型元数据和相同的 pose，不读取 GT，也不修改候选集合。

`4,961.17`。这证明页边界使用保守包围盒时没有漏掉后退视锥候选，也没有把页外实例错误加入结果。

## 结论边界

1. 空间页语义子门通过，可作为 Cold-0 的候选目录和固定特征分页输入。
2. 首轮至少需要约 `9.85 MB` 页数据，完整 7,999 pose 回放累计读取约 `13.79 MB`；这些字节必须计入冷启动
   资源预算，不能只报告 GLB 节省。
3. 本脚本是离线语义审计，没有测量浏览器网络、WebGPU dispatch、GPU compact、readback、主线程或内存，
   因此不产生 M9/M10 的 p50、p95、p99 性能结论。
4. 页面仍保持实例级候选输出；GLB 下载聚合不能替代实例级显示过滤。
